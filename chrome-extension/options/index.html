Permissions & honesty
  • Chrome: storage, identity, sidePanel, scripting, tabs; host access to Google APIs + http(s) pages (on-page audit + sitemap fetch).
  • OAuth: webmasters (read/write sites, analytics, sitemaps, inspection) + indexing.
  • Indexing API: Google documents service-account auth; user OAuth often 403. Prefer GSC Inspection → Request indexing.
  • GSC role: Owner (or Full) recommended for Inspection / sitemaps.
  • Unpacked extension IDs change if you reload from another path — re-register the Item ID.
